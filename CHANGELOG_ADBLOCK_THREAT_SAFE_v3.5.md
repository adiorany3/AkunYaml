# Changelog v3.5 Threat-Safe

- Menambahkan profil `threat-safe` sebagai turunan `app-safe`.
- Menambahkan HaGeZi Fake/Scam domain feed pada router.
- Menambahkan HaGeZi TIF IP extension pada OpenClash Auto dan Fresh Pool.
- OpenClash Lite sengaja tidak memuat TIF IP untuk menjaga RAM dan lookup tetap ringan.
- Android tetap YAML-only dan menggunakan provider malware, phishing/scam, serta cryptominer yang kompatibel.
- Menambahkan `threat_safe_audit.py`.
- Mempertahankan YouTube playback guard, streaming-safe, popup/game protection, app-safe, Turtlecute coverage, dan child-safe DNS.
- Tidak mengaktifkan NRD/DGA, blanket URL-shortener blocking, badware-hoster root blocking, atau abused-TLD blocking sebagai default.
