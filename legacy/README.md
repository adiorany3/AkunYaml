# Legacy files

File di folder ini dipertahankan hanya sebagai riwayat dari paket lama.
Jangan jalankan fixer Python di folder ini untuk target OpenClash v0.47.156 + Mihomo alpha-ge183c58.

Gunakan file aktif di root:

- `local_runner.py` untuk generate ulang.
- `apply_existing.py` untuk memperbaiki output yang sudah ada.
- `validate_openclash_target.py` untuk validasi.
- `openclash_router_fix.sh` untuk audit/fix pada OpenWrt.
- `openclash_exact_core_filter.sh` untuk isolasi node menggunakan exact core router.
